# To-Do List

Aplicação web para gerenciamento de tarefas, desenvolvida com HTML, CSS e JavaScript.

O projeto permite criar, editar, concluir e excluir tarefas, além de salvar os dados no navegador para que continuem disponíveis mesmo após atualizar a página.

## Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Concluir e reabrir tarefas
- Excluir tarefas
- Filtrar tarefas por status
- Contador de tarefas pendentes
- Remover tarefas concluídas
- Salvar tarefas no navegador com LocalStorage
- Modo claro e escuro
- Manter o tema escolhido após atualizar a página
- Adicionar tarefas pressionando Enter
- Layout adaptado para dispositivos móveis

## Como funciona

As tarefas são criadas e manipuladas através do JavaScript. Cada tarefa possui um identificador, um texto e um estado que indica se ela foi concluída.

O LocalStorage é utilizado para armazenar as tarefas no navegador. Dessa forma, os dados não são perdidos quando a página é atualizada.

A interface também possui filtros para facilitar a visualização das tarefas pendentes e concluídas.
